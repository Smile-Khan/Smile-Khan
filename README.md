## 🏆 Featured Projects

### 🌐 [Prism x Sentinel Nexus — CQRS-Based Distributed Discovery Engine](https://github.com/Smile-Khan/prism-sentinel-nexus)
**Flagship project — sole architect, designed end-to-end.**
- Full CQRS split — **Sentinel** (writes) + **Prism** (reads) — across a multi-module Maven monorepo.
- **Command side:** Java 21 Virtual Threads + Redisson distributed locking handle 10K+ concurrent requests with zero double-bookings and 95% CPU efficiency.
- **Query side:** Debezium CDC streams PostgreSQL WAL changes through Kafka into Elasticsearch for typo-tolerant fuzzy search, eliminating dual-write inconsistencies.
- Decoupled Kafka event emission from `@Transactional` blocks to prevent HikariCP pool exhaustion — cut DB lock contention by 40%, hit sub-200ms p99 latency under full load.
- Resilience: exponential backoff retries, Dead Letter Topics (DLT), global exception handling → **99.9% message delivery guarantee**.
- Full observability via Prometheus + Grafana: JVM thread states, connection pool health, ES indexing throughput.

### 🧑‍💼 [Employee Management System — Full-Stack CRUD Application](https://github.com/Smile-Khan/employee-management-system)
**Spring Boot + Spring Security + Spring Data JPA · React (Vite) + Tailwind CSS**
- Auto-generated employee/login IDs, DOB validation, PDF resume upload with file-size validation.
- Search and filtering by name, employee ID, login ID, DOB range, and department, with paginated results.
- Responsive CRUD views with Axios-based API integration and client-side routing via React Router.

### 💳 [Secure Payment Microservices System](https://github.com/Smile-Khan/spring-boot-payment-microservices)
**Backend & Security** — 4-tier decoupled payment lifecycle (Java 21) integrating with Trustly, secured via HMAC-SHA256 and RSA signatures for inter-service communication.

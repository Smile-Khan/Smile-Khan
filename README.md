## 🏆 Featured Projects

### 🔥 [Sentinel: High-Concurrency Distributed Ticketing Engine](https://github.com/Smile-Khan/sentinel-ticketing-engine)
**The Flagship Backend Project:** Solving the "Flash Sale" race condition problem.
- **Tech:** Java 21 Virtual Threads + Redisson Distributed Locking + Kafka.
- **Integrity:** Dual-layer protection (Redis + JPA Optimistic Locking) to ensure zero double-bookings.
- **Ops:** Real-time observability via Prometheus/Grafana.

### 💳 [Secure Payment Microservices System](https://github.com/Smile-Khan/spring-boot-payment-microservices)
**Backend & Security:** A production-style decoupled payment lifecycle.
- **Architecture:** 4-tier microservices (Java 21) integrating with Trustly.
- **Security:** Implemented HMAC-SHA256 and RSA signatures for secure service communication.

### ✅ [Full-Stack Task Manager](https://github.com/Smile-Khan/todo-app)
